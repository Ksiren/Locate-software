# Использование генеративного ИИ

## Запускаемая основа API

- Участник: M1 (lroofer).
- Задача: подготовить минимальный HTTP-сервис для демонстрации запуска на EK1 и структуру для дальнейшей реализации по Clean Architecture.
- Архитектура: M1 предложил использовать Clean Architecture; Codex помог детализировать структуру первоначального каркаса.
- Использование ИИ: Codex подготовил первоначальный каркас API, включая код, тест и конфигурацию зависимостей, и сгенерировал README.md.
- Результат: [фабрика приложения](src/locate/bootstrap.py), [HTTP-маршрут](src/locate/presentation/api/routes.py), [схема ответа](src/locate/presentation/api/schemas.py), [тест](tests/api/test_health.py), [зависимости](pyproject.toml), [их фиксация](requirements.lock), [README](README.md).
- Автоматическая проверка Codex 05.10.2026, macOS, Python 3.14.6: установка в заново созданное `.venv` по README, `pip check` без конфликтов, `pytest -q` - 1 passed без предупреждений, обе проверки Ruff успешны. После запуска Uvicorn запрос `curl -i http://127.0.0.1:8000/health` вернул HTTP 200 и `{"status":"ok"}`; сервер штатно остановлен через Ctrl+C.
- Проверка человеком: M1 проверил результат, оставил комментарии и внёс свои правки в формулировки и состав материалов. Правки по комментариям перенесены в файлы с помощью Codex.
